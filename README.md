Bedriftsnettverk – FjordTek AS

Om prosjektet

Jeg har jobbet med fysisk nettverk og bedriftsnettverk i Cisco Packet Tracer.

Fysisk nettverk

Jeg satte opp et nettverk med SERVER01, CLIENT01, switch og ruter. Jeg konfigurerte IP-adresser og DHCP og testet forbindelsen med ping.

Bedriftsnettverk

Jeg bygget et nettverk for FjordTek AS med Administrasjon, Support, Servere og Salg. Jeg konfigurerte IP-adresser, VLAN, statisk routing, DHCP, DNS og HTTP.

Testing

Jeg testet nettverket med ping, tracert og Simulation Mode. Jeg undersøkte ARP, ICMP, DNS, TCP og HTTP. I akseptansetesten fungerte routing og DNS, mens DHCP og HTTP fortsatt måtte kontrolleres.
